The first web 2.0 technologies that I learned about was Ajax is a program that to create interactive webpages without have to refresh or reload the web page. After Ajax I learned about folksonomy, which allows you to categorize online content through tags. folksonomy can be very helpful for research or just collecting information cause you tell it what you want, it also categorizes all the online content for you and just give you what you need. After folksonomy I learned about semantic web, which is a web application that can contextualize data while it processes the data. After being contextualized the data can then be augmented with metadata to give the data meaning. The last web 2.0 technologies that I learned about was a mashups, there are many types of mashups like mapping, housing maps, news, video and photo, and search and shopping mashups. A mashups is a website that combines the content from multiple different websites to make a new one. Mashups are very useful and we can use them all the time in our daily life's, we use shopping and searching mashups to get the best prices in the market, mapping mashups is very useful when you are driving cause it goes through all the routes on every map site and give you the best route possible, and news mashups are very helpful at keeping you informed on the topic that you are interested in.
