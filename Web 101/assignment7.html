For lesson seven's hands-on activities I learned about The three basic elements of networks Protocols, transmission media, and network services. Protocols is the communication rules that all network element must agree on and networks services are resources that are shared to all network users like printers. next I learned about network topology which are basic configurations that information systems personnel use to connect to nodes, topology can have wired and wireless connection. Then I learned about the different types of transmission media which are twisted-pair cable, coaxial cable, fiber-optic cable, and wireless technologies. Twisted-pair cable have two coppers wires intertwined inside of it, twisted-pair cable are the most used cabling systems in ethernet networks. There are two kinds of twisted-pair cables, there are shielded twisted -pair (STP) and unshielded twisted-pair (UTP). STP and UTP come in two varieties of wire, those varieties are standard which is used more commonly cause it is flexible and easier to handle, and solid which can span farther distances but it is less flexible so if it get bent to much it will break. Next I learned about coaxial cable which are commonly used by cable companies, coaxial cables have a single wire at the center which is surrounded by a metallic shield that serves as a ground. There are multiple types of coaxial cables for different purposes like baseboard cables, broadband cables, and television network cables. The last transmission media that I learned about was fiber-optic cables. Fiber-optic cables have two small glass strands one strand receives and the other strand sends. these strands are called the core, each core is surrounded by glass cladding. Fiber-optic cabling is the fasted transmission media, it transmits data at a gigabit-per-seconds range.
